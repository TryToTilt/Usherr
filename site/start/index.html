Let's start Usherr

All your media. One app.

Six steps get Usherr and Jellyfin running on your Windows PC. Each one says what to do, what you'll see, and how to fix it if it doesn't work. Once Usherr opens, it takes over and walks you through the rest.

About 30 minutesMost of it is waiting for downloads.
Nothing installed from hereYou install Docker from Docker's own site. This page only writes a small text file for you.
Pick up where you left offYour ticks and answers stay in this browser.

Not on Windows? Mac, Linux and NAS steps are on the way. Until then, see the install notes.

0 of 6 steps done
1
Check your PCCan it run Usherr?
2 min

Usherr runs inside Docker, which needs a 64-bit Windows 10 or 11 PC with a feature called virtualization switched on. Most PCs have it on already. This step checks.

Do this

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Click Performance (on the left), then CPU.
  3. Look under the graph for Virtualization.
  4. While you're there, click Memory: 8 GB is the minimum, 16 GB is comfortable.

What you'll see

Task Manager · Performance · CPU
Sockets:1Cores:8Logical processors:16Virtualization:Enabled

It says Virtualization: Enabled and you have 8 GB or more.

It didn't work

It says "Virtualization: Disabled"

It has to be switched on in your PC's BIOS (the settings screen before Windows starts). Software can't do this for you, but it's a one-time switch.

Search the web for "your PC brand and model" enable virtualization (for example "Dell XPS 15 enable virtualization"). The setting is usually called Intel VT-x, Intel Virtualization Technology, SVM Mode or AMD-V. Turn it on, save, and restart.

I don't see a "Virtualization" line

Click CPU on the left first; the line is under the graph, with Sockets and Cores. If it still isn't there, Windows may already be using it for something else, which is fine: carry on to step 2, and Docker will say if it can't start.

I have less than 8 GB of memory

Usherr may still start, but it will be slow next to Jellyfin and Windows. 8 GB is the realistic minimum.

2
Install Docker DesktopThe program that runs Usherr
10 min

Docker runs apps like Usherr and Jellyfin in tidy boxes called containers, so they don't mess with the rest of your PC and are easy to update or remove. You install it from Docker's own site; it's free for home use.

Do this

  1. Go to docker.com/products/docker-desktop and download Docker Desktop for Windows.
  2. Run the installer. Leave Use WSL 2 ticked. Restart your PC if it asks.
  3. Open Docker Desktop and accept Docker's agreement (that's yours to accept).
  4. It asks you to sign in: you can skip it. Skip the survey too.
  5. Wait until the bottom-left corner shows Engine running.
  6. Recommended: in Docker Desktop, Settings → General, tick Start Docker Desktop when you sign in, so Usherr is there after every restart.

What you'll see

Docker Desktop · bottom-left corner
Engine running

Docker Desktop is open and shows a green Engine running.

It didn't work

"WSL needs updating" or "WSL 2 installation is incomplete"

Right-click the Start button, choose Terminal (Admin), type wsl --update and press Enter. When it's done, restart the PC and open Docker Desktop again.

It stays on "Starting the Docker Engine…"

Give it two or three minutes the first time. If it's still stuck, restart the PC. If it then says "Virtualization support not detected", go back to step 1.

My C: drive is small

Docker keeps its own disk (where Usherr's downloads are unpacked) on C: by default. If C: has less than about 100 GB free, move it: Docker Desktop → Settings → Resources → Advanced → Disk image location, pick a bigger drive, then Apply. Do this now, before anything is downloaded.

Is Windows 11 Home OK?

Yes. Docker Desktop works on Home and Pro.

Save your setup filecompose.yaml, into your Usherr folder
1 min

This file tells Docker what to run and which folders it may use. It's plain text: you can open it in Notepad and read every line.

Finish step 3 first, then your file appears here.

Do this

  1. Click Download compose.yaml.
  2. Move it from your Downloads folder into C:\Usherr.

What's in it


      
The folder C:\Usherr holds a file named exactly compose.yaml.

      
It didn't work

      
The file is called compose.yaml.txt or compose (1).yaml

        
Rename it to exactly compose.yaml. To see the ending, in File Explorer click View → Show → File name extensions.

      

      
I want to change an answer
Go back to step 3, change it, press Make my setup file again, and download the new file over the old one.

Start itOne command
5–10 min
  

    
This is the only time you'll type a command. It tells Docker to download Usherr (and Jellyfin) and start them. From now on they start by themselves with Docker.

    
Do this

    
    
      
  1. In File Explorer, right-click your C:\Usherr folder and choose Open in Terminal.
    Windows 10: hold Shift while you right-click, and choose Open PowerShell window here.
    2. 
      
  2. Copy this, paste it into the window (right-click pastes), and press Enter:
    3. 
    

    
docker compose up -d

    
  1. Wait. The first time it downloads 1–2 GB, so it can take a few minutes.

    
What you'll see

The last lines say Started for each container, in green.

    
It didn't work

    
"docker is not recognized…"
Docker Desktop isn't running, or the window was opened before Docker was installed. Open Docker Desktop, wait for Engine running, close this window, and open a new one from the folder.

    
"no configuration file provided: not found"
The window isn't in your Usherr folder, or the file isn't named exactly compose.yaml. Check step 4, then open the terminal from the folder again.

    
"port is already allocated" or "address already in use"
Another program uses Usherr's or Jellyfin's port. In step 3, open Advanced, change the port (for example 8300), make the file again, save it over the old one, and run the command again.

    
"invalid mount" or "the system cannot find the path specified"
One of the folders in step 3 doesn't exist or has a typo. Create the folder (or fix the path), make the file again, and run the command again.

    
Windows asks whether to allow Docker on networks
Allow it on Private networks. That lets your phone and TV reach Usherr and Jellyfin at home. Don't tick Public.

    
It's taking ages
It's downloading. Leave the window open; it finishes on its own. You can check progress in Docker Desktop under Images.
